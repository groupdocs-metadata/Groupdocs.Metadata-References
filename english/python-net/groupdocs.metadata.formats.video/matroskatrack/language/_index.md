## language property

The language of the track in the Matroska languages form, which must be ignored if [`MatroskaTrack.LanguageIetf`](/metadata/python-net/groupdocs.metadata.formats.video/matroskatrack/language_ietf/) is used in the same TrackEntry.

Language codes can be either the three‑letter bibliographic ISO‑639‑2 form (e.g., "fre" for French), or such a language code followed by a dash and a country code for language specialities (e.g., "fre-ca" for Canadian French). Country codes are the same as used for internet domains.
