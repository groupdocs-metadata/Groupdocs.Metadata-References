## ENVELOPE_PRIORITY field

Optional, not repeatable. A single octet, consisting of a numeric character. Specifies the envelope handling priority and not the editorial urgency (see 2:10, Urgency). '1' indicates the most urgent, '5' the normal urgency, and '8' the least urgent copy. The numeral '9' indicates a User Defined Priority. The numeral '0' is reserved for future use.

### Value
`60`
