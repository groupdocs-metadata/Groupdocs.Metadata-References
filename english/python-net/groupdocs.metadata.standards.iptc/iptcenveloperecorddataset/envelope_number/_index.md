## ENVELOPE_NUMBER field

Mandatory, not repeatable, eight octets, consisting of numeric characters. The characters form a number that will be unique for the date specified in 1:70 and for the Service Identifier specified in 1:30. If identical envelope numbers appear with the same date and with the same Service Identifier, records 2-9 must be unchanged from the original. This is not intended to be a sequential serial number reception check.

### Value
`40`
